# Personal Portfolio Website

This project is my personal portfolio website developed as part of Phase 1 – Foundations: HTML5 and CSS3.

## Website Sections

- Home
- Profile
- CV
- Education and Technical Expertise
- Projects
- Activities/Gallery
- Contact

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

## Design Description

The website uses a clean and responsive layout. HTML5 semantic elements such as header, navigation, section, article and footer are used to organize the content. CSS Flexbox is used for layout, and media queries are used to make the website responsive on mobile devices.
