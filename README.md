## Website Sections

- Home
- Profile
- CV
- Education and Technical Expertise
- Projects
- Activities/Gallery
- Contact

## Technologies Used

The website was developed using:

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries

## Features

- Semantic HTML elements such as `header`, `nav`, `section`, `article` and `footer`
- Navigation menu for accessing different pages
- Personal profile section
- CV section with tables
- Education and technical skills information
- Projects section
- Activities and gallery section
- Contact form
- Embedded map using iframe
- Responsive design for mobile and desktop screens
- External CSS styling
- Flexbox layout
- Media queries
